# City Máquinas — site institucional

Site de divulgação institucional, desenvolvido inicialmente com HTML, CSS e JavaScript puro.

## Como visualizar
1. Baixe ou extraia a pasta do projeto.
2. Abra `index.html` no navegador.
3. Para desenvolvimento, recomenda-se usar a extensão Live Server no Visual Studio Code.

## Antes de publicar — personalizar
- Em `js/script.js`, substitua `5511999999999` pelo número oficial de WhatsApp (somente números, com 55 + DDD).
- Confirme se o Instagram é `https://www.instagram.com/citymaquinas/`.
- Revise o texto institucional, os produtos e os serviços com a empresa.
- Adicione endereço, horário de funcionamento e telefone, caso queiram divulgar essas informações.
- Substitua as ilustrações gráficas dos produtos por fotos reais autorizadas, se disponíveis.

## Estrutura
- `index.html`: conteúdo e estrutura das seções.
- `css/style.css`: cores, layout e responsividade.
- `js/script.js`: menu mobile, ano automático, cards interativos, janela de detalhes e links de WhatsApp.

## Interação dos produtos
Os cards mostram uma indicação ao passar o mouse (computador) e abrem uma janela com informações ao clicar ou tocar (celular). As descrições são gerais e devem ser revisadas pela City Máquinas antes da publicação.

## Observação
O conteúdo é um modelo inicial de divulgação. Não anuncia consertos, garantias, marcas autorizadas, endereço ou horários que ainda não foram confirmados.
