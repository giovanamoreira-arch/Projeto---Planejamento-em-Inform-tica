## Sobre o projeto

O projeto consiste no desenvolvimento de um site institucional para a City Máquinas, empresa especializada em peças para linha branca e refrigeração.

A proposta busca facilitar o acesso às informações sobre a empresa e seus produtos, além de contribuir para sua divulgação e presença no ambiente digital.

## Tecnologias utilizadas

- HTML5 — estrutura e conteúdo das páginas.
- CSS3 — estilização, layout e responsividade.
- JavaScript — funcionalidades e interações do site.

## Como visualizar o projeto

1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta no Visual Studio Code ou outro editor.
3. Abra o arquivo `index.html` em um navegador.

Para facilitar a visualização e o desenvolvimento, recomenda-se utilizar a extensão **Live Server** no Visual Studio Code.

## Estrutura do projeto

- `index.html` — estrutura e conteúdo principal do site.
- `css/style.css` — estilos, layout e responsividade.
- `js/script.js` — funcionalidades e interações.

## Funcionalidades

- Navegação entre as seções do site.
- Menu adaptado para dispositivos móveis.
- Exibição de produtos em cards interativos.
- Janela com informações adicionais dos produtos.
- Links para contato via Instagram.
- Acesso ao Instagram da empresa.
- Atualização automática do ano no rodapé.
